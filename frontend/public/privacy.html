プライバシーポリシー

最終更新日: 2026年8月22日

1. 本ページについて

本ページは、「プロ野球志望届データ管理システム」（以下「本システム」）における個人情報の取り扱いについて、個人情報保護法に基づき公表するものです。本システムは個人が運営する非商用のデータ分析ツールです。

2. 収集するデータと取得元

本システムは、以下の公開情報を取得元の公式サイトから収集しています。

  • 高校生: 都道府県・所属学校名・氏名・届出日
  • 大学生: 地区・所属学校名・氏名・ふりがな・届出日

取得元は、各連盟が公式サイトで一般に公開しているプロ志望届提出者の公示です。

  • 日本高等学校野球連盟「プロ志望届提出者」 https://www.jhbf.or.jp/pro-aspiring/
  • 全日本大学野球連盟「プロ志望届提出者」 https://www.jubf.net/system/prog/procandidate.php

本システムは各連盟とは関係のない第三者が運営しています。連盟による公示は、本システムによる収集・データベース化・公開への本人の同意を意味するものではありません。

3. 利用目的

  • プロ野球志望届データの集計・分析
  • 統計情報の生成・表示
  • 個人を識別できない集計・分析結果の、本サイト上での公開
  • 認証済み管理者によるデータの確認・訂正・削除およびシステム運用
  • システムの運用・改善

選手個人への連絡・勧誘・マーケティング、個人への評価付けやランキング表示は行いません。

4. データの保存と管理

  • 保存場所: AWS（Amazon Web Services）東京リージョン
  • 閲覧: 認証なしで閲覧できるのは、個人を識別できない集計ダッシュボードのみです。氏名を含む高校生一覧・大学生一覧、検索、更新・削除、スクレイピング履歴・実行は AWS Cognito の admin 権限を必須とし、運営者のみが操作できます
  • 検索エンジンへの掲載は robots.txt と noindex 指定で拒否しています（本ページと利用規約のみ、削除窓口を見つけていただくためクロールを許可しています）
  • S3サーバーサイド暗号化（AES-256）等の安全管理措置を実施
  • 保持の必要性を年1回見直し、不要と判断したデータは削除

5. 第三者への提供

収集した氏名その他の個人データを第三者に販売・貸与したり、認証なしで公開したりすることはありません。認証なしで公開するのは、個人を識別できない年度別・区分別・地域別・日次の集計結果に限ります。専門家の確認なく実名一覧の一般公開へ戻すことはありません。

6. 未成年者のデータについて

収集対象には高校生（未成年者）の情報が含まれます。この点を踏まえ、氏名を含むデータは管理者限定とし、認証なしでは個人を識別できない集計だけを表示します。利用停止・削除を求める請求は、本人・保護者いずれからでも下記7の手続きで受け付けます。

7. 開示・訂正・利用停止・削除の請求（削除窓口）

選手本人（未成年者の場合は保護者等の法定代理人を含む）から、自己のデータに関する開示・訂正・利用停止・削除の請求を受け付けます。請求に手数料はかかりません。

削除・掲載停止のお申し出先
メール: yuta.nozue@gmail.com
件名の例: 「掲載停止の請求」

お手数ですが、本文に次の内容をご記入ください。

  1. ご本人の氏名（本サイトに掲載されている表記）
  2. 所属学校名
  3. プロ志望届の届出年度（分かる範囲で構いません）
  4. ご請求の内容（開示・訂正・利用停止・削除のいずれか）
  5. ご連絡先メールアドレス
  6. 法定代理人・保護者の方が請求される場合は、その旨とお名前

受け付けた後の対応は次のとおりです。

  • ご本人または法定代理人であることを、上記の記載内容の照合など合理的な方法で確認します（過剰な本人確認書類は求めません）
  • 受付から原則2週間以内に、該当データの削除または利用停止を実施し、結果をご連絡します
  • 削除後は除外リストに登録し、以後の定期収集で再び取り込まれないようにします。過去年度の掲載分についても同時に非表示になります
  • 対応できない正当な理由がある場合は、その理由をご回答します

なお、本システムが削除できるのは本システムが保有する情報に限られます。取得元である各連盟の公式サイトの公示や、検索エンジン・第三者のサイトに残る情報については、本システムから削除することはできません。それぞれの運営者へお問い合わせください。
