# プロ野球志望届データ管理システム
#
# 方針: サイトを一般公開した後も、検索エンジンには掲載しない（2026-08-19 時点）。
# 実在の高校生（未成年者）の氏名を含むデータを扱うため、氏名で検索してヒットする状態を
# 作らないことを最優先し、クローラーによる収集・インデックスを全面的に拒否する。
# 一般公開の方針（2026-08-18 決定）でも noindex の継続は前提に含まれている。
#
# ---------------------------------------------------------------------------
# 先行サイトの実測調査（2026-08-19 実施。curl による実取得）
# ---------------------------------------------------------------------------
#
# 1. 球歴.com（kyureki.com）— 中学〜社会人までを収録する最大級の選手データベース。
#    掲載対象がうちと最も近い。
#    - robots.txt: 全面 Disallow ではない。選手プロフィール直下 `/player/{id}/` は許可し、
#      検索・ランキング・一覧・ログイン・バッチ等の動的／ユーティリティ系を広範に Disallow。
#    - `User-agent: meta-externalagent`（Meta の AI クローラー）だけは全面 Disallow。
#    - 重要: クロールを許可したうえで、選手ページ単位で `noindex,nofollow` を出し分けている。
#      実測12ページでは、経歴が高校止まり・記録の薄い選手（例: 秋田商のみ、長野商のみ、
#      日大明誠のみ、逗子開成のみ）はいずれも noindex。プロ・社会人・大学まで経歴が続く
#      選手は index。つまり「まだ公人といえない高校生」は検索結果に出さない運用。
#
# 2. ドラフト・レポート（draft-repo.com）— ドラフト候補紹介サイト。
#    robots.txt は `Disallow: /tb.php/` のみ、sitemap 公開、トップは `index,follow`。実質フルオープン。
#
# 3. ドラ要素＠のもとけ（dnomotoke.com）— 野球ニュースまとめブログ。
#    WordPress 既定の `Disallow: /wp-admin/` のみ、sitemap 公開。実質フルオープン。
#
# ---------------------------------------------------------------------------
# 判断: 全 Disallow を維持する
# ---------------------------------------------------------------------------
#
# - 2 と 3 はオープンだが、いずれも記事・論評コンテンツが主体で、氏名の一括データベースを
#   人名検索でヒットさせる構造ではない。うちは志望届提出者の氏名一覧そのものであり、性質が違う。
# - 掲載対象が最も近い 1 が、まさに「経歴が高校止まりの選手」をページ単位で noindex にしている。
#   うちの掲載対象はほぼ全員がその区分に当たる。先行サイトに倣うなら結論は「索引させない」。
# - 可逆性が非対称。robots.txt を後から緩めるのは即日できるが、いったん索引された氏名を
#   消すのは削除申請で数週間かかり、キャッシュや二次サイトへの伝播は取り返せない。
#   削除請求フロー（#L2 で3件のバグを修正したばかり）が実運用で回った実績がまだない段階で、
#   先に開ける理由がない。
# - 将来 1 と同じ「ページ単位で出し分ける」運用に寄せる余地は残す。その場合も解禁は
#   本方針そのものの見直しとセットで行うこと。
#
# 例外として、プライバシーポリシーと利用規約だけはクロールを許可する。
# 削除請求の窓口（掲載停止の申し出先）は、掲載されている本人が見つけられなければ
# 意味がないため。どちらのページにも選手の個人情報は載せていない。
#
# sitemap.xml は掲載しない方針の間は不要と判断して作成していない。
# 掲載を解除する際に、この Disallow の緩和とあわせて追加する。

User-agent: *
Disallow: /
Allow: /privacy.html
Allow: /terms.html
