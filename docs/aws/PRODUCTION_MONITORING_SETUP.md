# プロダクション監視体制設定ガイド

## 概要

本ドキュメントでは、AWS 無料枠を最大限活用したプロダクション監視体制の設定方法を説明します。
月額コスト$0.00〜$0.10 の範囲で 24 時間監視を実現します。

## 監視コンポーネント

### 1. CloudWatch Dashboard（無料枠：3 個まで）

プロダクション環境のみダッシュボードを作成し、以下のメトリクスを表示：

- **Lambda 関数メトリクス**

  - 実行回数（Invocations）
  - エラー率（Error Rate）
  - 実行時間（Duration）
  - 成功率（Success Rate）

- **システムヘルスメトリクス**

  - 24 時間の Lambda 実行回数
  - 24 時間のエラー数
  - 平均実行時間
  - 成功率パーセンテージ

- **コスト監視**
  - 推定コスト（USD）
  - 無料枠使用率（%）

### 2. CloudWatch Alarms（無料枠：10 個まで）

重要度の高い 4 つのアラームのみ設定：

1. **Lambda 関数エラーアラーム**

   - しきい値：5 分間で 3 回以上のエラー
   - 評価期間：2 期間

2. **統合エラーアラーム**

   - しきい値：全 Lambda 関数で 5 回以上のエラー
   - 評価期間：3 期間

3. **実行時間アラーム**

   - しきい値：平均 5 分以上
   - 評価期間：2 期間

4. **コスト警告アラーム**（最重要）
   - しきい値：$0.50 以上
   - 評価期間：1 期間

### 3. X-Ray トレーシング（無料枠：月 10 万トレース）

- Lambda 関数の分散トレーシング有効化
- API Gateway → Lambda → S3 のフロー可視化
- パフォーマンスボトルネック特定

### 4. SNS 通知（無料枠：月 1,000 通）

- メールアドレスへのアラート通知
- 重要度に応じた通知設定

## セットアップ手順

### 1. 環境変数設定

```bash
# アラート通知先メールアドレスを設定
export ALERT_EMAIL="your-email@example.com"
```

### 2. CDK デプロイ

```bash
cd pro-candidate-aws
npm install
cdk deploy ProBaseballStack-prod --parameters alertEmail=$ALERT_EMAIL
```

### 3. メール認証

デプロイ後、指定したメールアドレスに AWS SNS から確認メールが届きます。
リンクをクリックして認証を完了してください。

### 4. ダッシュボード確認

デプロイ完了後、CloudWatch コンソールで以下を確認：

```
https://console.aws.amazon.com/cloudwatch/home?region=ap-northeast-1#dashboards:name=pro-baseball-system-prod
```

## コスト最適化のポイント

### 1. ダッシュボード最適化

- prod 環境のみダッシュボード作成（1 個のみ使用）
- dev/staging 環境は CloudWatch Logs Insights で代替

### 2. アラーム最適化

- 重要な 4 つのアラームのみ設定（無料枠 10 個中 4 個使用）
- 複合メトリクスで効率化

### 3. ログ管理

- CloudWatch Logs の保持期間を 7 日間に設定
- 必要最小限のログレベル（prod 環境は WARN 以上）

### 4. X-Ray 最適化

- サンプリングレート調整（必要に応じて）
- 重要なトランザクションのみトレース

## 監視運用

### 日次確認項目

1. **エラー率確認**

   - Lambda 関数のエラー率が 5%未満か
   - アラート通知の有無

2. **パフォーマンス確認**

   - 平均実行時間が 3 秒以内か
   - タイムアウトの発生有無

3. **コスト確認**
   - 日次コストが$0.02 未満か
   - 無料枠使用率が 80%未満か

### 週次確認項目

1. **ログ分析**

   - CloudWatch Logs Insights でエラーパターン分析
   - パフォーマンス改善点の特定

2. **X-Ray 分析**
   - サービスマップの確認
   - レイテンシー分布の確認

## トラブルシューティング

### アラートが届かない場合

1. SNS サブスクリプションの確認
2. メールアドレスの認証状態確認
3. スパムフォルダの確認

### コストが想定を超える場合

1. Lambda 実行回数の確認
2. CloudWatch Logs のデータ量確認
3. 不要なメトリクスの削除

## まとめ

この設定により、以下が実現されます：

- **24 時間監視体制**：自動アラートで即座に問題検知
- **コスト管理**：月額$0.10 以内で運用可能
- **パフォーマンス最適化**：ボトルネック特定と改善
- **高可用性**：99.9%以上の可用性を監視

無料枠を最大限活用し、エンタープライズレベルの監視を実現します。
