プロ野球志望届システム

AWS サーバレスアーキテクチャ

環境: dev / prod（完全分離構成） | バージョン: v1.4.0

📊 システム概要

日本の高校生・大学生のプロ野球志望届データを収集・分析する AWS サーバーレスアプリケーション。完全無料枠内での運用を実現し、スケーラブルで低コストな運用を提供します。

💰 運用コスト

  • 月額: $0.00 - $0.50
  • 完全無料枠内運用
  • 自動スケーリング対応
  • コスト監視アラート設定済み

🔧 主要技術

  • Lambda (Node.js 18.x)
  • S3 + JSON ベースストレージ
  • CloudFront CDN配信
  • EventBridge スケジューラー

🌐 環境構成

  • dev: 開発・テスト環境
  • prod: 本番運用環境
  • 完全分離バケット構成
  • 独立認証設定

✅ 品質保証

  • E2Eテスト: 61件
  • TypeScript 厳密型チェック
  • ESLint + SonarQube
  • 自動デプロイメント
🌐 レイヤー1: 外部アクセス層
👤
エンドユーザー
ユーザータイプ: 管理者・開発者・閲覧者
アクセス方法: Webブラウザ (Chrome, Firefox, Safari, Edge対応)
認証: AWS Cognito (dev/prod環境別)
ユーザー → HTTPS → CloudFront → S3 Website (React SPA)
☁️ レイヤー2: CDN / フロントエンド配信層
🌐
CloudFront (CDN)
機能: エッジロケーション配信・HTTPS強制・カスタムドメイン対応
キャッシュ戦略: 静的アセット(31536000s)・HTML/JS(300s)
配信: グローバルエッジロケーション
📦
S3 Bucket (Static Website)
コンテンツ: React SPA・PWA対応・Service Worker
SPA Routing: 404 → index.html リダイレクト設定
暗号化: AES-256
🔐
AWS Cognito (認証)
機能: ユーザー認証・セッション管理・環境別分離
dev環境: UserPool ap-northeast-1_yRTv0CRfz
prod環境: UserPool ap-northeast-1_5m7pnXzt8
CloudFront → API Gateway → Lambda → S3 Data
🔌 レイヤー3: API Gateway層
⚡
API Gateway (REST API)
エンドポイント:
• GET /health - ヘルスチェック
• GET /players - 選手データ取得
• GET /years/available - 利用可能年度取得
• POST /scraping/trigger - スクレイピング実行
• GET /scraping/history - 実行履歴取得

機能: CORS有効化・認証統合・レート制限・リクエスト検証・ログ記録
⚙️ レイヤー4: Lambda / サーバレス処理層
λ
Lambda: API処理
ランタイム: Node.js 18.x
メモリ: 128MB
タイムアウト: 30秒
機能: S3データ読み取り・レスポンス返却・エラーハンドリング
λ
Lambda: スクレイピング処理
ランタイム: Node.js 18.x
メモリ: 512MB
タイムアウト: 15分
機能: NPBサイトスクレイピング・データ検証・S3保存・履歴記録・メール通知

v1.4.0新機能: 実行制限ロジック
• Frontend手動実行: 1日1回制限
• EventBridge定期実行: 制限なし
• S3履歴管理: execution-tracking/last-execution.json
λ
Lambda: SPA Custom Resource
実行タイミング: CDKデプロイ時
機能: S3 Website設定自動適用・SPA Routing対応（404→index.html）
Infrastructure as Code: 手動設定不要
⏰ レイヤー5: EventBridge / スケジューラー層
⏰
EventBridge Rule
prod環境: 17:30 JST 毎日実行
dev環境: 5分間隔（テスト用）
ターゲット: Lambda スクレイピング関数
イベントペイロード: {type: 'both', year: 2025, source: 'EventBridge'}
