### 2. 実装内容

#### 日別履歴保存機能（S3 history/ディレクトリ）

**実装関数**: `saveDailyHistory()`
- 毎日のスクレイピング実行時に選手データのスナップショットをS3に保存
- 保存パス: `history/{type}/{year}/{YYYY-MM-DD}.json`
- 保存データ:
  - 日付、タイプ、年度
  - 選手数
  - 選手リスト（ID、名前、学校、ポジション）

#### 前日データ比較ロジック

**実装関数**:
1. `getPreviousPlayers()`: 前日の選手データをS3から取得
2. `detectNewPlayers()`: 現在と前日のデータを比較して新規選手を検出

**比較方式**:
- 選手IDベースの差分計算
- 前日データが存在しない場合は全選手を新規として扱う

#### メールテンプレートの改善

**新メソッド**: `sendScrapingCompletionEmailWithNewPlayers()`

**メール内容の変更**:
- 件名: 新規選手数を表示（例：【新規3名】プロ野球志望届）
- 本文:
  - 実行情報（日時、種別、年度、環境、総件数）
  - 新規選手リスト（高校生/大学生別）
  - 選手ごとに名前、学校、ポジションを表示

**メール出力例**:
```
件名: 【新規2名】プロ野球志望届 - 高校生・大学生

====================
実行情報
====================
日時: 2025/09/24 10:00:00 (JST)
種別: 高校生・大学生

環境: prod環境
総件数: 165件

====================

====================

【高校生】1名
--------------------
山田太郎 (東京高校 / 投手)

【大学生】1名
--------------------
佐藤次郎 (明治大学 / 捕手)
```

### パフォーマンス考慮事項

- 履歴保存は非同期処理でメイン処理をブロックしない
