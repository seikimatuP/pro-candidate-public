## 技術的知見

### AuthHelperクラスの正しい使用方法

```typescript
// ❌ 誤り: 静的メソッド呼び出し
await AuthHelper.login(page);

// ✅ 正しい: インスタンスメソッド呼び出し
const authHelper = new AuthHelper(page);
await authHelper.login();
```

### サーバーレスアーキテクチャでのE2Eテスト

- local環境でもローカルAPIサーバーは不要
- dev/prod環境の実際のLambda APIを使用
- `http://localhost:3000`（存在しない）→ `https://...amazonaws.com/dev/`（実API）

### GitHub Actions ワークフロー再実行の制限

- `gh run rerun`は元のコミット時点のワークフロー定義を使用
- 新しいワークフロー定義を使うには新しいイベント（PR更新等）が必要
- Dependabot PRの場合: `@dependabot rebase`でトリガー可能

### TypeScript tsconfig.json exclude設定

```json
{
  "include": ["src"],
  "exclude": ["src/services/legacy/**"]
}
```

- レガシーコードをTypeScriptコンパイルから除外
- 歴史的記録として保存しつつビルドエラー回避
