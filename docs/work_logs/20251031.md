## 技術的知見

### Git Revert vs Delete in CDK

**誤った方法**: Infrastructure as Code でコードを完全削除

```typescript
// ❌ 誤り: ルール定義全体をコメント化
// const scrapingScheduleRule = new events.Rule(...);
```

**正しい方法**: ランタイム フラグで状態制御

```typescript
// ✅ 正しい: enabled フラグで制御
const scrapingScheduleRule = new events.Rule(this, 'ScrapingScheduleRule', {
  enabled: false, // ランタイム無効化・復旧容易
  // ... other configuration
});
```
