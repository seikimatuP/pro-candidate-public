### 5. 技術的課題と解決

**課題1: draw.io CLI不在**

- 問題: 公式draw.io CLIがnpmレジストリに存在しない
- 調査: `@hediet/drawio-cli`、`draw.io-cli` → 両方404エラー
- 解決: Puppeteer + HTML生成による代替アプローチ実装

**課題2: Puppeteerモジュール解決**

- 問題: グローバルインストールではプロジェクト内からrequire()不可
- エラー: `Error: Cannot find module 'puppeteer'`
- 解決: `npm install --save-dev puppeteer` でローカルインストール

**課題3: スクリプト実行フロー**

- 問題: 同期処理でHTML生成→非同期でPDF生成の統合
- 解決: IIFE（即時実行関数）でasync/awaitラップ
- 結果: シームレスな自動実行フロー確立
