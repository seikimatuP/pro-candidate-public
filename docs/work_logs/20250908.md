## 実施内容

### 1. ダッシュボード機能の改善

#### 1.1 スクレイピング結果0件時のグラフ表示改善

**問題点:**

- スクレイピング結果が0件の場合、グラフが「データが存在しません」と表示されていた
- 0件でも履歴として重要な情報なので、グラフに0として表示されるべき

**修正内容:**

1. **Dashboard.tsx の修正**

   - データが0件の場合でも、現在の日付で0件のデータポイントを作成
   - 空配列を返すのではなく、0値のデータポイントを生成

   ```typescript
   if (playersData.data.length === 0) {
     const today = new Date().toISOString();
     return [
       {
         date: today,
         highschoolCount: 0,
         universityCount: 0,
         totalCount: 0,
       },
     ];
   }
   ```

2. **TrendChart.tsx の修正**
   - labelsが存在してdatasetsが空の場合、デフォルトで合計データセットを表示
   - グラフ表示条件を`labels.length > 0 && datasets.length > 0`に修正
   - エラーメッセージを適切に分岐（データなし vs データセット未選択）

#### 1.2 データ再取得の最適化

**問題点:**

- ダッシュボード画面リロード時にデータが再取得されない可能性があった

**修正内容:**

- `loadAllPlayersData`関数を`useCallback`でメモ化
- 依存配列に`selectedYear`を追加
- 重複していた`useEffect`を統合し、依存配列を`[selectedYear, availableYears, loadAllPlayersData]`に設定
- React Hooksのベストプラクティスに準拠
