## ダッシュボードのリロード時データ再取得問題修正（2025-09-06 22:10）

### 問題の詳細

- ダッシュボード画面をリロードしてもグラフの情報が再取得されない可能性があった

### 原因分析

- `loadAllPlayersData`関数が`useCallback`でメモ化されていなかった
- `useEffect`の依存配列に`loadAllPlayersData`が含まれていなかった
- これにより、関数が再作成されても`useEffect`が反応しない問題があった

### 実施した修正

1. **useCallbackによるメモ化**

   - `loadAllPlayersData`を`React.useCallback`でラップ
   - 依存配列に`selectedYear`を追加

2. **useEffectの依存配列修正**
   - 年度変更時のuseEffectから重複していた初回ロード用useEffectを削除
   - 依存配列を`[selectedYear, availableYears, loadAllPlayersData]`に統一

### 修正の効果

- ページリロード時に確実にデータが再取得される
- 年度変更時の再取得も正常動作
- React Hooksのベストプラクティスに準拠
