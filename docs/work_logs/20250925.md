# 作業日誌 2025年9月25日

## 作業概要

prod環境でEventBridge定期実行（17:30）のメール通知が送信されない問題を解決

## 実施内容

### 1. 問題の調査と特定

- **問題**: prod環境で17:30の定期実行メール通知が送信されない
- **原因**: 1日1回実行制限がEventBridgeとFrontend両方に適用されていた
- **影響**: E2Eテストなどで日中に実行すると、17:30の定期実行がブロックされる

### 2. 修正内容

**Lambda関数の実行制限ロジック改善** (`pro-candidate-aws/lambda/scraping.js`)

```javascript
// 修正前: EventBridgeとFrontend両方に制限適用
if (environment === 'prod' && (isEventBridgeSource || event.source === 'Frontend'))

// 修正後: Frontendのみに制限適用
if (environment === 'prod' && event.source === 'Frontend')
```

主な変更点：

- EventBridge定期実行は1日1回制限から除外
- Frontend手動実行のみ1日1回制限を維持
- 実行日時の記録もFrontendのみに限定
