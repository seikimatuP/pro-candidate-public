## フロントエンド環境変数整理とService Worker削除

### 環境変数ファイルの整理

#### 問題

- `.env.prod`と`.env.production`の重複
- 不要な`.env`と`.env.development`ファイル

#### 実施内容

1. **削除**: `.env`, `.env.development`, `.env.production`
2. **GitHub Actions修正**: 環境変数コピー処理を削除、`npm run build:dev/prod`を直接使用
3. **package.json修正**: `--mode prod`で`.env.prod`を直接読むように変更

#### 最終構成

```
frontend/
├── .env.dev      # dev環境用
├── .env.prod     # prod環境用
├── .env.local    # ローカル開発用
└── .env.example  # サンプル
```

### Service Worker完全削除とキャッシュ無効化

#### 問題

- dev環境でデータが最新ではない
- Service Workerがまだ動作している

#### 実施内容

1. **App.tsx強化**

   - Service Worker強制削除
   - Active Service Worker検出と自動リロード
   - キャッシュ完全削除
   - localStorage/sessionStorageのPWA関連データ削除

2. **api.ts改善**

   - キャッシュ無効化ヘッダー追加
   - タイムスタンプパラメータ自動付与

3. **確認方法**
   - DevTools → Application → Service Workers（登録なし確認）
   - コンソールで削除ログ確認
   - APIリクエストに`_t`パラメータ確認
