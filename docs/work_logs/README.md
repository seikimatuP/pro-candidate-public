- **例**: `20250902.md`（2025年9月2日の作業日誌）

## 作業日誌の書き方

各作業日誌には以下の項目を記載します：

1. **作業概要** - その日の主な作業内容の要約
2. **実施作業** - 具体的に実施した作業の詳細
3. **成果物** - 作成・更新したファイルや機能
4. **次のステップ** - 今後の課題や予定
5. **作業時間** - 開始・終了時刻と合計時間
6. **備考** - その他の注意事項や気づき
