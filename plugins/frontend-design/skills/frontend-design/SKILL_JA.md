このスキルは、AIっぽい「量産型デザイン」を避けた、独自性のある本格的なフロントエンドインターフェースの作成をガイドします。美的なディテールと創造的な選択に細心の注意を払い、実際に動作するコードを実装します。

ユーザーはフロントエンドの要件を提供します：構築するコンポーネント、ページ、アプリケーション、またはインターフェースです。目的、対象ユーザー、技術的制約についてのコンテキストが含まれる場合もあります。

## デザイン思考

コーディングの前に、コンテキストを理解し、**大胆な**美的方向性にコミットしてください：

- **目的**: このインターフェースはどんな問題を解決するか？誰が使うか？
- **トーン**: 極端なスタイルを選ぶ：徹底的なミニマル、マキシマリストの混沌、レトロフューチャー、オーガニック/自然派、ラグジュアリー/洗練、遊び心/トイライク、エディトリアル/雑誌風、ブルータリスト/生々しい、アールデコ/幾何学的、ソフト/パステル、インダストリアル/実用的など。選択肢は無限にあります。インスピレーションとして参考にしつつ、美的方向性に忠実なデザインを作成してください。
- **制約**: 技術要件（フレームワーク、パフォーマンス、アクセシビリティ）
- **差別化**: 何がこれを**忘れられない**ものにするか？誰もが覚えている一つのことは何か？

**重要**: 明確なコンセプトの方向性を選び、精度を持って実行してください。大胆なマキシマリズムも洗練されたミニマリズムも、どちらも有効です。重要なのは強度ではなく、意図性です。

その後、以下の特徴を持つ動作するコード（HTML/CSS/JS、React、Vueなど）を実装します：

- 本番グレードで機能的
- 視覚的にインパクトがあり記憶に残る
- 明確な美的視点で一貫性がある
- あらゆるディテールが入念に洗練されている

## フロントエンド美学ガイドライン

以下に注力してください：

- **タイポグラフィ**: 美しく、ユニークで、興味深いフォントを選ぶ。Arial や Inter などの汎用フォントを避け、フロントエンドの美学を高める独自の選択をする。予想外で個性的なフォント選び。特徴的なディスプレイフォントと洗練された本文フォントを組み合わせる。
- **カラー＆テーマ**: 一貫した美学にコミットする。一貫性のためにCSS変数を使用。控えめで均等に分散されたパレットよりも、支配的な色とシャープなアクセントの方が効果的。
- **モーション**: エフェクトとマイクロインタラクションにアニメーションを使用。HTMLにはCSSのみのソリューションを優先。利用可能な場合はReact用にMotionライブラリを使用。インパクトの高い瞬間に集中：散発的なマイクロインタラクションよりも、スタガーリビール（animation-delay）を使った巧みに演出されたページロードの方が喜びを生む。驚きを与えるスクロールトリガーとホバー状態を使用。
- **空間構成**: 予想外のレイアウト。非対称性。オーバーラップ。斜めの流れ。グリッドを破る要素。余白を贅沢に取るか、コントロールされた密度か。
- **背景＆ビジュアルディテール**: ベタ塗りをデフォルトにするのではなく、雰囲気と奥行きを作る。全体の美学に合ったコンテキストに応じたエフェクトとテクスチャを追加。グラデーションメッシュ、ノイズテクスチャ、幾何学パターン、レイヤード透過、ドラマチックなシャドウ、装飾的なボーダー、カスタムカーソル、グレインオーバーレイなどのクリエイティブな表現を適用。

以下のような汎用的なAI生成の美学は**絶対に使用しない**：使い古されたフォントファミリー（Inter、Roboto、Arial、システムフォント）、ありきたりな配色（特に白背景に紫グラデーション）、予測可能なレイアウトとコンポーネントパターン、コンテキスト固有の個性が欠けた量産型デザイン。

創造的に解釈し、コンテキストに合った本物のデザインに感じられる予想外の選択をしてください。どのデザインも同じであってはならない。ライトテーマとダークテーマ、異なるフォント、異なる美学を使い分ける。世代を超えて共通の選択（例：Space Grotesk）に収束しない。

**重要**: 実装の複雑さを美的ビジョンに合わせる。マキシマリストなデザインには、広範なアニメーションとエフェクトを伴う精巧なコードが必要。ミニマリストや洗練されたデザインには、抑制、精度、スペーシング、タイポグラフィ、繊細なディテールへの注意が必要。エレガンスはビジョンをうまく実行することから生まれる。

覚えておいてください：Claudeは並外れたクリエイティブな仕事ができます。型にはまらず、独自のビジョンに完全にコミットしたときに本当に何が作れるかを見せてください。

## 使用例

### 基本的な呼び出し方

```
@SKILL_JA.md ダッシュボードを作成して
```

### 詳細なリクエスト例

```
@SKILL_JA.md

プロ野球選手一覧ページをデザインして

目的: スカウト向けの選手データ閲覧
トーン: スポーツ新聞風・躍動感
制約: React + TypeScript、モバイル対応
差別化: 選手カードをトレーディングカード風に
```

### トーン別デザインアイデア

| トーン                | 特徴                               | 適用例                         |
| --------------------- | ---------------------------------- | ------------------------------ |
| エディトリアル/雑誌風 | 大きな見出し、余白の活用、写真中心 | ニュースサイト、ポートフォリオ |
| ブルータリスト        | 生々しい、太いボーダー、モノクロ   | 実験的サイト、アート系         |
| レトロフューチャー    | ネオン、グリッド、80年代風         | ゲーム、エンタメ系             |
| ラグジュアリー        | 金/黒、セリフ体、繊細なアニメ      | 高級ブランド、金融系           |
| オーガニック          | 曲線、アースカラー、手書き風       | 自然派、健康系                 |
| トイライク            | 丸み、ポップな色、バウンスアニメ   | 子供向け、カジュアルアプリ     |
